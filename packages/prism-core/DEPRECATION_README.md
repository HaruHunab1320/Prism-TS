# ⚠️ DEPRECATED - prism-uncertainty has moved!

**This package has been moved to `@prism/core`**

## Migration Instructions

```bash
# Uninstall old package
npm uninstall prism-uncertainty

# Install new package
npm install @prism/core
```

## What's Changed?

- Package name changed from `prism-uncertainty` to `@prism/core`
- Now part of the `@prism/*` ecosystem with additional packages:
  - `@prism/llm` - LLM provider integrations
  - `@prism/confidence` - Confidence extraction utilities
  - More coming soon!

## Why the Change?

We're building a comprehensive ecosystem for uncertainty-aware programming. The `@prism/*` namespace better reflects this vision and allows us to ship modular, focused packages.

## Need the Old Version?

The last version of `prism-uncertainty` (v1.0.21) will remain available, but will not receive updates. We strongly recommend migrating to `@prism/core`.
