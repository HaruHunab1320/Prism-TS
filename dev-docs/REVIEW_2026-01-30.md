# Prism State Review — 2026-01-30

## Scope

## Confirmed Fixes / Already Implemented
These items are documented as gaps in older docs but are implemented in the codebase now.

- **Module system runtime support**: import/export parsing + runtime execution + cache + resolution in `packages/prism-core/src/{parser.ts,runtime.ts,module-system.ts}`.
- **Async/await + Promise built-ins**: `AwaitExpression` in parser/runtime and `Promise` built-ins in `packages/prism-core/src/runtime/builtins/async.ts`.
- **try/catch/finally**: `TryStatement` parsing + runtime handling in `packages/prism-core/src/{parser.ts,runtime.ts}`.
- **Confident ternary (`~?`) + confident assignment operators (`~+=`, `~-=`, `~*=`, `~/=`)**: tokens + parser rewrites + runtime in `packages/prism-core/src/{tokenizer.ts,parser.ts,runtime.ts}`.
- **Confident property access (`~.`)**: implemented via `resolvePropertyAccess` in `packages/prism-core/src/runtime.ts`.
- **Module cache invalidation + reload**: `invalidateModule` / `reloadModule` in `packages/prism-core/src/runtime.ts` and tests in `packages/prism-core/test/module-system.test.ts`.
- **LLM streaming**: `stream_llm` builtin and `Runtime.streamLLM` in `packages/prism-core/src/runtime.ts` and `packages/prism-core/src/runtime/builtins/llm-stream.ts`.
- **`runPrism` helper**: present in `packages/prism-core/src/helpers.ts` and documented in `packages/prism-core/README.md`.
- **CLI run/eval/llm commands**: implemented in `apps/cli/src/index.ts` (contradicts older review notes).
- **VS Code extension exists**: `vscode-extension/prism-lang` with grammar + themes.

## Outstanding Gaps / Still-Unfixed Issues
These are real gaps verified in code and should be tracked in a fresh doc rather than relying on older checklists.

1. **Pattern matching not implemented**
   - No `match`/pattern syntax in tokenizer or parser; docs mention it (e.g. root `README.md`, `dev-docs/FUTURE_FEATURES.md`).

2. **“Agent/consensus/aggregation” patterns are documentation-only**
   - `PATTERNS.md` shows `consensus`, `chain`, `aggregate`, `parallel` constructs that do not exist in parser/runtime.

3. **Strict scoping/TDZ not complete**
   - **Resolved:** assignments now require declarations and TDZ is enforced for `let`/`const`.

4. **Diagnostics only partially integrated**
   - **Resolved:** runtime errors now emit diagnostics and CLI/REPL format them; validator emits richer diagnostics for streaming fallback.

5. **Validator drift still present**
   - **Resolved:** streaming fallback covers full keyword/operator set; errors include location and fallback context.

6. **Confidence strategy/provenance not configurable**
   - Confidence combination is hard-coded (mostly min/max/product) in `applyBinaryOperatorWithConfidence` and not wired to `@prism-lang/confidence` strategy APIs.

7. **`null` vs `undefined` unification not done**
   - **Resolved:** `undefined` now maps to `null` and `UndefinedValue`/`UndefinedLiteral` are removed.

8. **Keyword casing cleanup not done**
   - Tokenizer still accepts `Agent` (capitalized) in addition to `agents`.
